Deskripsi Tugas

Tugas ini merupakan latihan mandiri mata kuliah Pemrograman Visual menggunakan bahasa pemrograman Java. Terdapat empat latihan yang membahas penggunaan perulangan dan method dalam program.

Daftar Latihan

1. Latihan Pertama – Nomor Urut Barang
   
   Menggunakan perulangan "for" untuk menampilkan nomor barang dari 1 sampai 10, kemudian dari 10 sampai 1.

2. Latihan Kedua – Simulasi Stok
   
   Menggunakan perulangan "while" untuk mengurangi stok barang dari 5 hingga habis.

3. Latihan Ketiga – Method Kembalian
   
   Membuat method "hitungKembalian()" untuk menghitung uang kembalian berdasarkan uang pembayaran dan total harga.

4. Latihan Keempat – Method Daftar Barang
   
   Membuat method "tampilkanDaftarBarang()" dengan tipe kembalian "void" untuk menampilkan daftar barang sesuai jumlah pembelian.

Tujuan

Memahami penggunaan perulangan "for", "while", serta method dalam bahasa pemrograman Java agar program menjadi lebih terstruktur dan mudah dipahami.
